Sync between your devices

Episodes are encrypted on this device with your passphrase, then stored in a private GitHub repository you own. GitHub only sees scrambled data. Use the same repository and passphrase on the laptop and the phone.

How to set this up (5 minutes, once)
  1. On GitHub, create a new private repository, for example dayline-data. Leave it empty.
  2. Go to Settings → Developer settings → Fine-grained tokens → Generate new token. Choose Only select repositories → that repository. Under Repository permissions set Contents: Read and write. Copy the token.
  3. Fill in the fields below on each device, with the same passphrase. Pick a passphrase you won't forget: it can't be recovered.

Claude (notes and chat)

Notes and chat use Claude through your own API key from console.anthropic.com. The key stays on this device. Each conversation's text is sent to Anthropic when notes are made or when you ask a question, so check that your company allows this for work meetings.

With Haiku, notes for a 45-minute call cost about $0.002 and a new chat about $0.01, so a $5 credit lasts a long time. The cost of a new chat is shown under the question box.

Backup file

If GitHub is blocked on a device, move conversations with an encrypted file instead (for example through OneDrive or email to yourself). Uses the passphrase above.
